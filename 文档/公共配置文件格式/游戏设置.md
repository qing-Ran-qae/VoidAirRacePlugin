# 游戏设置

| 字段名               | 类型        | 描述         | 默认值         |
|-------------------|-----------|------------|-------------|
| `selected_map_id` | `String`  | 当前选中地图的 ID | `GrassLand` |
| `match_duration`  | `Integer` | 比赛的持续时间    | `12000`     |
| `max_arenas`	     | `Integer` | 	最大竞技场数量	  | `4`         |
